# Parcel Duty Calendar — Lanna 2 Dormitory (PCSHS Chiang Rai)

ตารางเวรรับพัสดุหอพักล้านนา 2 โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย เชียงราย

## Features
- **Bilingual UI (EN / TH):** Switchable interface with Gregorian (EN) and Buddhist Era (TH) years.
- **12 Monthly Festival & Holiday Themes:** Automatic seasonal palettes, masthead motifs, holiday markers, and optional ambient effects for every month (e.g., Songkran in April, Yi Peng & Loy Krathong in November, Winter Festive in December).
- **Flexible Rotation:** Includes weekends by default (`skipWeekends = false`), with a quick toggle, click-to-edit per day, and customizable room sequence.
- **Clean Export (PNG & PDF):** Exports the calendar and duty schedule without "Today" markers.

## Deploy on GitHub Pages (via GitHub Desktop)
1. Open this repository in **GitHub Desktop** and click **Publish repository**.
2. On GitHub.com, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** (`main` / `/ (root)`) or **GitHub Actions** (using `.github/workflows/deploy.yml`).
